# 장기 연습판 — 3단계

기본 `janggi` 규칙을 사용하는 장기 앱의 첫 실행 가능한 단위입니다.
Node.js 내장 HTTP 서버와 Fairy-Stockfish 공식 규칙 바인딩 `ffish-es6@0.7.10`을 사용합니다.

## 실행

Node.js 22 이상이 필요합니다. 프로젝트 폴더의 터미널에서:

```text
npm ci
node server/index.js
```

현재 PC에는 의존성 설치가 완료되어 있습니다. PowerShell에서 npm 실행 정책 오류가 나면 `npm.cmd ci`를 사용하세요.

브라우저에서 <http://127.0.0.1:3000>을 엽니다. 종료는 터미널에서 Ctrl+C입니다.
테스트는 `node --test`로 실행합니다. 테스트에도 아래 실제 엔진이 필요합니다.

### 장기 엔진

현재 개발 PC에는 `.local/fairy-stockfish_x86-64.exe`를 배치했습니다.
다른 PC에서는 [공식 장기 배포](https://github.com/fairy-stockfish/Fairy-Stockfish-NNUE/releases/tag/janggi-9991472750de-new)의
Windows `fairy-stockfish_x86-64.exe`를 해당 경로에 넣습니다.
Linux 등에서는 호환되는 장기 NNUE 내장 엔진의 절대 경로를 `JANGGI_ENGINE_PATH` 환경 변수로 지정합니다.
이번 실행 검증은 Windows만 대상으로 했습니다.

엔진: Fairy-Stockfish 120825 LB / NNUE: janggi-9991472750de.nnue.
실행 파일 SHA256: `d9fd87ae91f2226d741d436d5dbc548416c66d77297e84ef7ee8fbe2a9d29e50`.
`.local`은 버전 관리에서 제외합니다. 엔진은 GPLv3이며 외부 배포 전 [THIRD_PARTY.md](THIRD_PARTY.md)를 확인합니다.

## 이번 단계에서 되는 것

- 한 화면에서 초·한을 번갈아 조작하는 연습판.
- AI 상대 대국: 초·한 선택, 자동 응수, 생각 중 취소·재개.
- 엔진이 생성한 합법 수 강조와 착수 검증.
- 한수쉼, 한 수 무르기, 초기화, 착수 기록.
- 실제 장기 NNUE 엔진으로 300ms 탐색한 추천 수 표시.
- 화면 폭에 맞는 장기판과 키보드로 누를 수 있는 기물·자리 버튼.
- 초·한 각 4가지, 총 16개 초기 차림 선택. 순서는 각 진영이 바라보는 왼쪽부터입니다.
- 빅장 수락, 연속 한수쉼, 반복·무포획 수 제한, 외통에 대한 종료 판정.
- 승자·종료 이유·기물 점수 표시, 종료 후 착수·AI 추천 차단, 무르기로 재개.

기물을 누르고 표시된 도착점을 누르면 착수합니다. AI 추천은 자동 착수하지 않습니다.
화면의 기물은 가독성을 위해 한글로 표시합니다.

AI와 두려면 대국 방식에서 **AI 상대 대국**과 내 진영을 선택하고 **선택한 설정으로 새 대국**을 누릅니다.
한을 고르면 AI가 먼저 두며, 내 진영이 화면 아래에 표시됩니다.
생각 중 취소는 판을 유지하고 AI 응수를 일시정지합니다. 재개하면 다시 탐색합니다.
AI 대국에서 무르기는 내가 마지막 수를 두기 전으로 돌아가며 상대의 응수도 함께 되돌립니다.
내 첫 착수 전에는 무르기를 사용할 수 없습니다. AI 오류가 나면 재개로 재시도할 수 있습니다.
AI 탐색은 300ms이며 난이도 선택은 아직 없습니다.

## 현재 범위

현재 엔진은 **개발 PC의 Node 서버에서 실행**합니다. 휴대폰 CPU 분석은 아직 구현하지 않았습니다.
합법 수와 종료 판정은 `server/rules.js`의 공식 바인딩이 담당하고 추천 탐색은 기존 실행 파일이 담당합니다.
반복 등 청구 가능한 종료 조건도 `result(true)`로 자동 적용하는 정책입니다.
기보 전체를 재생하므로 현재 배치만 같고 반복 이력이 다른 상황을 구분합니다.

기물 점수는 차 13, 포 7, 마 5, 상·사 3, 졸·병 2이며 한에 1.5점을 더해 표시합니다.
승자는 표시 점수를 비교해 자체 결정하지 않고 엔진 결과를 사용합니다.
기본 `janggi`에서는 일반 반복도 점수 판정으로 끝날 수 있습니다. 빅장을 피하면 계속 진행하며,
한수쉼으로 수락하면 점수로 끝납니다. 두 번 연속 한수쉼도 점수 판정입니다.
[공식 API](https://github.com/fairy-stockfish/Fairy-Stockfish/wiki/API),
[종료 규칙 소스](https://github.com/fairy-stockfish/Fairy-Stockfish/blob/master/src/position.cpp),
[기물 점수 구현](https://github.com/fairy-stockfish/Fairy-Stockfish/blob/master/src/position.h).

규칙 바인딩은 `Fairy-Stockfish 230826 LB`, 추천 엔진은 `120825 LB`입니다.
16개 초기 차림의 배치·합법 수가 두 엔진에서 일치하는지 테스트하고, 추천 수를 규칙 바인딩으로 재검증합니다.
모든 중·종반에서 버전 간 규칙 일치를 입증한 것은 아니므로 배포 전 회귀 사례를 확대해야 합니다.
대국 시계·시간패·기권 및 온라인 대국 운영은 아직 구현하지 않았습니다.

로컬 서버 전체가 하나의 연습판을 공유하며, 서버를 재시작하면 기보가 초기화됩니다.
여러 탭에서 동시에 착수하면 오래된 요청은 거부합니다. 화면은 500ms 간격으로 상태를 조회합니다.
외부 공개 배포·계정·결제·온라인 대전용 구조는 아직 아닙니다.

## 구성과 이어서 할 일

- `public/`: 장기판과 조작 화면.
- `server/engine.js`: 엔진 명령과 응답 해석. 요청별 별도 프로세스 사용.
- `server/rules.js`: 차림 생성, 합법 수·승패 판정, 기물 점수.
- `server/game.js`: 기보·착수 검증·상태 변경.
- `server/index.js`: 로컬 HTTP 서버와 요청 순서 제어.
- `test/game.test.js`: 실제 엔진 및 HTTP 통합 검증.
- `test/ai.test.js`: 자동 응수, 취소·재개·무르기 충돌, 실제 엔진 응수와 중단 검증.
- `test/rules.test.js`: 16개 차림 대조, 빅장·점수승·반복·외통·종료 후 처리 검증.
- [PROGRESS.md](PROGRESS.md): 짧은 작업 단위와 다음 시작점.

무료는 휴대폰에서 빠른 리뷰, 유료는 서버에서 정밀 리뷰를 제공하는 방향을 유지합니다.
이번에는 엔진 연결을 먼저 검증했습니다. 브라우저 엔진 연결 시 동일한 `janggi` 규칙과 전체 착수 이력을 사용해야 합니다.
